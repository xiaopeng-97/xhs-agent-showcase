小红书选题仿写员

给一批关键词，它自动采集小红书爆款笔记、分析选题、产出原创仿写草稿，并整理进飞书多维表格。全程飞书对话可见，人工确认后发布。

了解它怎么工作

本页为静态展示，演示对话为真实运行录像还原，不接入任何 API、不暴露账号数据，他人无法调用。

它是什么

一个专职做小红书内容前端调研与仿写的数字员工——一机一职，只做这一件事。

2.5h→15min

一组关键词（3个词+找达标笔记+3篇仿写）的耗时，从手工约2.5小时降到约15分钟。

100% 数据真实

互动数据为真实抓取，达标少如实报数，绝不编造、不放宽门槛充数。

3 篇原创仿写

每组按实用清单/情绪共鸣/场景故事三种差异化角度产出原创草稿，非搬运。

三个工具怎么分工

脸、大脑身体、后勤各司其职，这是它稳定运行的关键。

输入 / 触发方式

你需要给什么

  • 关键词清单：3个同方向词，如「小学语文资料、小学数学资料、幼小衔接资料」
  • 采集门槛：如「近1个月内、赞+评+藏合计≥3500」
  • 目标人群：如「小学生家长和老师」
  • 归档去向：默认写入飞书多维表格

怎么让它开工

  • 在飞书「小红书采集二创」对话发一条完整指令
  • 首次或 cookie 失效：扫码登录小红书
  • 它自动跑完并回传多维表格链接
  • 发布前逐条人工审核，"通过"才发

能力边界（做不了 / 需人工）

它不会做

  • 不绕风控、不用代理池、不高频批量请求
  • 不做无人值守全自动发布
  • 不编造数据、不放宽门槛充数、不用推荐流冒充搜索
  • 不改自身 profile / 密钥 / 配置

需要人工介入

  • cookie 失效 → 人工扫码登录
  • 采集为空或风控 → 人工切手动采集
  • 方向/关键词/人群调整 → 人工给意见
  • 发布前 → 人工逐条审核放行
