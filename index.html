● 在线

输入与触发。

你需要给什么

  • 关键词清单：3 个同方向词，如「小学语文资料、小学数学资料、幼小衔接资料」
  • 采集门槛：如「近 1 个月内、赞+评+藏合计 ≥ 3500」
  • 目标人群：如「小学生家长和老师」
  • 归档去向：默认写入飞书多维表格

怎么让它开工

  • 在飞书「小红书采集二创」对话发一条完整指令
  • 首次或 cookie 失效：扫码登录小红书
  • 它自动跑完并回传多维表格链接
  • 发布前逐条人工审核，"通过"才发

它的能力边界。

清楚它做不了什么，才能长期稳定地用好它。

它不会做

  • 不绕风控、不用代理池、不高频批量请求
  • 不做无人值守全自动发布
  • 不编造数据、不放宽门槛充数、不用推荐流冒充搜索
  • 不改自身 profile / 密钥 / 配置

需要人工介入

  • cookie 失效 → 人工扫码登录
  • 采集为空或风控 → 人工切手动采集
  • 方向 / 关键词 / 人群调整 → 人工给意见
  • 发布前 → 人工逐条审核放行
